# docs/ui - UI audit and M49 design mockups

Design-first work for M49 (docs/ROADMAP.md item 2). Each mockup is one self-contained HTML file (open it in a browser;
a 390 px phone frame first, a 1440 px desktop frame below; light / dark follow the system, or use the switch). Mock data
only. Nothing in a mockup is built until the owner approves it.

- [UI_AUDIT.md](UI_AUDIT.md) - UI-H Part 1 audit (24 Oct 2026).
- [U3_LIBRARY.html](U3_LIBRARY.html) - U3 Strategy library: plain cards (name, one line, at most 3 settings, the rest under "More settings" and (?)), one-row category chips, a one-line empty state, desktop master-detail. Waits for the owner's approval.
- [U6_SCREENER.html](U6_SCREENER.html) - U6 Find setups (Screener): one "Start a scan" block (Ready scan / Template / Own words), "Matched N of M" once after a run, the old "Custom scan" page folded into the Conditions block, no "Autopilot" wording. Waits for the owner's approval.
