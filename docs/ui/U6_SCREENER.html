What changes (for approval)

  • One start: "Start a scan" is one block with one chooser: Ready scan, Template or Own words. Today these are three separate starts.
  • "Matched N of M" once: it appears only in the results header, only after a run. The phone bar keeps Save and Run, no second count.
  • Custom scan folded in: the old "Custom scan" page is the "Conditions" block. "Blank: I add conditions" in Template starts from zero. The old address and the search word "custom scan" open this page with Conditions open.
  • No "Autopilot" wording. The next step after a run is "Tell me when it matches".
  • Disabled buttons say why: "Pick a scan first" beside Run.
  • Empty states collapse: no results box before the first run; Conditions stays one line until opened.
  • Hero: your list and chart in words, each with "Change". Rarely used tools go under "More tools".
  • Desktop: three columns: start, conditions, results.
