0. Current state (frontend/src): ProChart.tsx (483 lines) on lightweight-charts ^4.2.3 — candles, volume, EMA/SMA/Bollinger/VWAP/Supertrend overlays, RSI/ADX panes, timeframe pills, live LTP, lazy older history, priceLines/zones/markers props, strategies drawn on and deployed from the chart (Phase AO). CandleChart.tsx (mini), ChartWindow.tsx (pop-out), EquityCurveChart. Total charting code ≈1,300 lines, 9 indicators.
 Missing for a world-class platform: drawing tools (trendlines, channels, Fibonacci, rectangles/zones, text) with save/load and sync across timeframes; 100+ indicators and user-scriptable indicators; chart types (Heikin Ashi, Renko, range, line, area, hollow); multi-chart layouts (2/4/6/8) with symbol/TF link; compare/overlay symbols; bar replay; volume profile / session breaks; magnet/snap; templates and layouts saved per user; keyboard shortcuts; chart → alert / chart → screen / chart → order-draft actions; price_action engine overlays (swings, legs, zones, trendlines, liquidity pools) as first-class layers; options overlays (OI walls, max pain, expected move, payoff); screenshots/share to Telegram.

1. Decision: dual-track, one abstraction.
 Track A — TradingView Advanced Charts (proprietary; free with the TradingView logo; licensed to companies for public web apps, not personal/testing use; access by application; source not provided). Gives 100+ indicators, 80–110+ drawing tools, chart types, multi-chart layouts, saving via our storage, replay, custom studies through its JS API. Abhi applies with the company/product details (business action; log in OPEN_QUESTIONS; do not block on it).
 Track B — open-source: upgrade lightweight-charts 4.x → 5.x (plugins / ISeriesPrimitive), build our drawing layer on primitives (evaluate vendoring deepentropy/lightweight-charts-drawing — 68 tools for v5, early-stage 0.1.x, license must be confirmed before use; otherwise implement our own core set: trendline, ray, horizontal/vertical, parallel channel, rectangle/zone, Fibonacci retracement/extension, text, long/short position, measure). KLineChart (Apache-2.0, built-in indicators + drawing overlays + custom indicators) is the fallback engine if primitives prove too slow to build.
 Both tracks sit behind one ChartEngine interface (frontend/src/charting/engine.ts): setSymbol/TF, setBars/appendBar (live), addStudy/removeStudy, addDrawing/updateDrawing/removeDrawing, serialize/deserialize layout, overlay API for platform layers (price_action, options, trades, screener hits), event hooks (crosshair, click, drawing changed, visible range). ProChart becomes the embedded/mini implementation of the same interface; the full "Charts" workspace uses the best available engine (feature-flag per tenant). All platform value (layers, drawings storage, alerts, actions) lives above the interface so switching engines never loses user data.

2. Platform layers (engine-agnostic, these are the differentiators):
 - Price-action layer from the backend engine: swing highs/lows, legs/impulse vs corrective, S/R zones with lifecycle state (fresh/tested/flipped/invalidated — invalidated only when the structural swing beyond it breaks), trendlines/channels, liquidity pools and sweeps, trapped-trader zones, commitment candles, Dow trend label per timeframe, MTF top-down panel (W/D/1H/15m). Toggle per concept; significant levels only by default, debug mode shows everything.
 - Options layer (index/F&O symbols): OI walls (max CE/PE OI strikes) as horizontal bands, max pain, expected move cone from straddle, PCR badge, IV rank badge, payoff of an open or draft spread overlaid on price; option chain side panel linked to the crosshair.
 - Trades layer: executed/paper trades, draft proposals (monitor state machine), SL/target lines draggable → proposal update (never direct order; ADR-0006), P&L on chart.
 - Screener layer: screen hits as markers/badges on the bar they triggered; "why it matched" tooltip.
 - Option-contract charts (first-class, not only overlays on the underlying): any option contract (e.g. a specific strike/expiry CE or PE) and any futures contract opens as its own chart with full engine features — candles, volume, OI as a pane, IV as a pane, Greeks (delta/theta/vega) panes, OI-change bars, premium vs underlying compare. Spread charts: synthetic series for a strategy (bull put, bear call, iron condor, straddle/strangle) computed server-side from the leg premiums — net premium candles, net Greeks, P&L vs time; same for calendar/diagonal. Straddle/strangle premium charts per expiry (ATM rolling), IV charts (ATM IV, IV rank/percentile history, IV skew curve by strike with history slider), PCR history chart, max-pain history, OI-by-strike bar chart (CE/PE) with change vs previous day and intraday OI build-up chart, futures basis/cost-of-carry chart, participant-wise OI (FII/DII/Pro/Client) history, rollover chart near expiry. Option symbol search understands underlying + expiry + strike + right; one click from the option chain, a position, a draft spread or a screener F&O hit opens the contract chart; underlying chart ⇄ option chart linked crosshair (time). Contract history survives expiry (expired contracts remain chartable from the data lake). Data: option candles/OI/IV from broker or vendor feeds (seams), Greeks and IV computed server-side (one library shared with backtest/risk), expiry calendar from instruments/nse_expiries. Tests: synthetic spread series equals sum of legs on fixtures; Greeks parity with backtest library; expired contract still loads; crosshair link across underlying/option.
 - Breadth/RRG mini panels dockable beside the chart.
 - Drawings: server-side storage per user/symbol (all timeframes share drawings by time/price), versioned, undo/redo, lock, templates; export/import JSON.
 - Chart actions: create alert from a level/drawing (Notification Service §4 of SCREENER_SPEC), "find similar setups" → screen builder prefilled, "ask Copilot about this chart" (chart state → tool facts, numbers from data not pixels), "propose trade from drawing" → PAPER proposal, snapshot → Telegram/email/clipboard.
 - Multi-chart workspace: layouts 1/2/4/6/8, symbol/TF/crosshair link groups, saved layouts, watchlist-driven navigation, keyboard shortcuts, full-screen pop-out (existing ChartWindow).
 - Indicators: all backend ScreenQL/Strategy DSL functions available as chart studies (one computation library server-side for parity between screener, backtest and chart); user custom indicators = ScreenQL expressions plotted (no Pine, no arbitrary JS).
 - Replay: bar-by-bar with the price_action layers recomputed as-of each bar (no look-ahead) — doubles as the engine's visual test harness.
 - Chart types: Heikin Ashi, Renko, range, line/area, hollow candles; session breaks; extended-hours/crypto 24×7 time axis; venue calendars from v1.2.
 - Performance: 50k+ bars smooth, WebWorker for indicator math, incremental live updates, memory caps per chart.
