Store per (symbol, interval) with last-bar bookkeeping; features read locally.
PL-2 Budgets = each broker's PUBLISHED limits from its docs, all windows (per second, per minute, per 30 min, per day), separate pools for data vs orders, held per credential in Redis (shared by every process), with a safety margin as a setting (default 10 %). PL-3 Order of reads: store → missing newest bars by REST (paced) → never the full history per run. A second run on the same symbols makes zero history calls (test).
