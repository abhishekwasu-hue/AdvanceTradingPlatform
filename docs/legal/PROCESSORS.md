# Processor register (DPDP)

Status: draft for the owner and the lawyer. It lists every third party that handles users' personal data, found in the code and in `.env.example`. It holds no secret, server address or key: those live only in the server `.env`.

Why: DPDP Act s.8(2) allows a processor only under a valid contract with security safeguards (checklist row D25), and s.11(1) lets a user ask who received their data (D8). The user's "Download my data" ZIP carries the same list as `processors.json` (names and purposes in `backend/app/legal/processors.py`; a test keeps this file and that list in step).

**Contract status** is the owner's to fill in. No contract is claimed here: every row says "To be confirmed by the owner / lawyer" until the signed agreement or the provider's standard data-processing terms have been checked and the date written in.
