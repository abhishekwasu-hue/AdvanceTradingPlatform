What changes (for approval)

  • Page template: icon + one-word title + one line; a two-number summary; no help paragraph at the top.
  • Card: plain name, one plain line, at most 3 settings as chips. The rest sits under "More settings", and a hard word has its own (?).
  • Plain names: no raw setting keys and no "Indicator-based" label; the category is a word a trader uses.
  • Category chips stay on one line and scroll sideways; each shows its count. Tap "Options" to see the empty state.
  • Empty state is one short line with "Show all", never an empty box.
  • Desktop: master-detail. The list on the left; the chosen strategy's full settings on the right.
  • Wording: strategies "mark" structure. No buy / sell / target words; no prices; no results claims.

How it reads the chart
