# ATP ORDER M72 - AI Copilot rebuild (owner order, 1 Nov, verbatim)

M72 · ATP · AI COPILOT REBUILD — trader-friendly, advanced, grounded (owner not satisfied with today's Copilot)
Finding (code main): backend/app/ai/copilot_chat.py routes each message by keywords to 10 fixed jobs and answers from fixed rules; an LLM only re-words when the user brings his own key, otherwise "AI is off — answers are from rules"; the chart job says the full price-action reader is not in ATP; the tool-calling agent (ai/agent.py) and one-key AI are OFF. Result: rigid, prose-heavy, often "I don't know". Research R34: leading platforms ship an LLM agent over the platform's own data (chart analysis, plain-English scans/indicators/strategies, portfolio Q&A, order PREVIEW with user confirmation, proactive alerts); Indian brokers keep insight separate from execution with manual confirmation (SEBI).
Rules kept: information and education only, never "buy/sell" advice; AI never places, blocks or changes an order (it may PREPARE a ticket the user confirms himself); every number shown comes from a tool result (grounding check stays, failing lines dropped); exits never affected; PAPER/LIVE same; no hard-coded trading choices (M68) — the Copilot reads the user's own settings.
CP-0 Eval first: a set of 60 real trader questions (Marathi/Hindi/English; index options seller, swing trader, intraday trader, beginner) with expected grounded answers; score today's Copilot (answered / correct / useful / format) and post the table. The same set gates every PR (score must rise, never fall).
CP-1 Real agent: replace the keyword router with an LLM planner that calls ATP read tools (engine structure + areas from M66, option chain + OI/PCR, Greeks/payoff, positions + P&L + risk, orders, journal, screener run, backtest run, news/events, user settings, market data store) in several steps, then answers. Works out of the box with the platform AI key (flag ai_one_key, metered per plan, cost cap per user/day as a setting); the user's own key optional. Fallback to today's rule answers only when the model is down.
CP-2 Answer format: one-line headline, then numbers-first cards (tables, chips, small charts drawn by code — annotated chart with areas/levels/strikes), "How I worked this out" behind (?), follow-up chips ("Show on chart", "Make this an alert", "Backtest this", "Open in Terminal"). Markdown rendered, never raw; phone-first.
CP-3 Context everywhere: an "Ask AI about this" action on charts, option-chain rows, positions, orders, signals, screener results, journal entries — the Copilot opens with that object as context. The Copilot knows the current page, symbol and timeframe.
CP-4 Chart understanding: "Read this chart" on any symbol/TF uses the engine (M66) + vision (M59 hybrid); upload or TradingView snapshot link in the chat; annotated image back with areas, structure, trend, nearest areas of interest, invalidation levels — "area of interest" wording, no calls.
CP-5 Plain English → tools: scans ("NIFTY 50 stocks pulling back to a Daily demand area"), custom indicators, alerts, strategy drafts, backtests — each shown as an editable draft the user saves/runs; the Copilot explains the result.
CP-6 Options-seller toolkit: strike finder by the user's own rules (distance, delta, premium, OI walls), payoff + Greeks + margin, what-if (spot/IV/days), expiry checklist, adjustment scenarios shown as numbers (never a recommendation), combined-exit levels in index points/₹.
CP-7 Proactive watch (opt-in per alert type): positions near the user's own SL/target, short strike distance shrinking, delta/IV jump, OI shift at the user's strikes, a signal on his watchlist — delivered in-app/Telegram as short cards with "Ask why" link; personal pre-market brief and EOD wrap built from his positions and watchlist.
CP-8 Coach: weekly review from the journal (M62) — rule adherence, mistakes tagged, best/worst setups, numbers only; asks the user's own questions back ("Was this entry in your plan?").
CP-9 Ticket preparation (owner decision logged, default ON): from a chat the Copilot can PREFILL an order/spread ticket with the user's own settings; it opens the ticket, the user reviews and presses Place himself. No auto-execution, no "agent wallet".
CP-10 Languages + voice: answers in the user's chosen language (English/Marathi/Hindi), numbers and symbols unchanged; voice input on phone.
CP-11 Memory: per-user preferences learned from settings and past chats (instruments, timeframes, style), shown and editable in Settings › AI; never shared across users.
Deliver in order CP-0 → CP-1 → CP-2 → CP-3 → CP-6 → CP-4 → CP-5 → CP-7 → CP-8 → CP-9 → CP-10 → CP-11; each PR with the eval score, phone + desktop screenshots, cost per answer, tests (grounding, no-advice filter, no order without user click).
